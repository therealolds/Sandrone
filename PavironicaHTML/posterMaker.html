Poster Maker

Local-only · No uploads

Load a screenshot of a print you're thinking of buying, set its real size, and this tool slices it into printable sheets at 1:1 scale — tape them to the wall to see how the print looks and fits before you buy it.

How to proceed

  1. Generate the sheets, then press "Print".
  2. In the print dialog, set the scale to 100% / Actual size (not "Fit to page"), otherwise the measurements will be wrong.
  3. Trim (if you like) along the overlap edge and line the sheets up using the corner marks.
  4. Tape the sheets to the wall to get a real sense of size and position before buying the actual print.

1. Image

Take a screenshot of the print on the website and paste it here with Ctrl+V (no need to save it first), or drag in an image file, or use the file picker.

2. Size & print options

The margin accounts for the edge many printers can't reach. The overlap duplicates a strip of image on the edges of adjacent sheets so they're easier to line up when you tape them together.
