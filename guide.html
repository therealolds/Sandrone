Sandrone – Tool Guide

Every tool runs entirely in your browser. Nothing is uploaded or stored on any server. This guide explains what each tool does, how to use it, and the less obvious features.

Data visualization

JSON Viewer

View, navigate, search and compare JSON files — with up to three documents side by side.

Open tool →

Layout

The viewer is a single fixed workspace with three panes: the editor on the left, the interactive tree in the middle, and a tools rail (path, search, extractor, view options) on the right. Nothing appears or disappears below the fold — each pane scrolls on its own. The editor can be collapsed to a thin strip with the ◀ collapse button (click the strip to bring it back), giving the tree the full width.

Loading JSON

Three ways, all rendered immediately — the tree updates automatically as the content changes, no button to click:

  • Paste — press Ctrl+V anywhere on the page (not just inside the editor); the clipboard content replaces the editor.
  • Drop — drag a .json / .txt file anywhere onto the page.
  • Open file — the button in the toolbar.

Click Format to pretty-print the content (configure the indent width, 0–10 spaces, with the number field).

The editor has a line-number gutter on the left. Even and odd rows are shaded differently so you can track a line number at a glance. If the JSON is invalid, the offending line turns red in the gutter and an error banner appears below with the exact line, column, and parser message. Click ↳ Jump to line N in the banner to move the cursor straight there.

Memory slots (M1 / M2 / M3)

Three slots hold JSON documents alongside the editor. They survive a page reload (kept in the browser's session storage) and are cleared when the tab is closed. Each slot is a single chip in the toolbar:

ActionHow
Save editor content into the slotShift / Ctrl / Alt + click the chip
Show / hide the slot as a tree columnClick the chip
Load the slot back into the editorDouble-click the chip
RenameRight-click the chip

The chip label shows a truncated version of the custom name (if set) and a * when data is stored. The full stored content is shown in the chip tooltip. The Input chip works the same way for the editor's own column.

The tree

The JSON renders as a collapsible tree, fully collapsed by default. Each node expands or collapses with the + / - toggle; Alt+click a toggle to expand or collapse that whole subtree at once. Click any line to see its full path in the Selected path panel on the right (e.g. root>glossary>GlossDiv>title>). During a search, the panel also shows the current match number and the matched value.

Multi-column view

Clicking slot chips adds or removes tree columns, so you can view the editor content and up to three stored documents side by side.

  • At least one column always remains visible.
  • When multiple columns are shown, each has its own independent tree. Clicking a node in any column makes that column active — the path panel, the search pane, and the extractor will then operate on it (a small label indicates which slot is active).

Tools rail

The right-hand rail has four sections:

  • Selected path — shows the full path of the last clicked node, and during a search, the current match's path, match index, type, and value.
  • Advanced search — described in detail below.
  • Key value extractor — collects values for a key (see below).
  • View — tree font size control.

Advanced search

The search panel operates on the active column's JSON. Text search and number search can be combined in a single query — only nodes matching both are returned.

FieldWhat it does
Text searchMatches any key or value that contains the term. Enable Case sensitive to make the match exact-case, or % to treat % as a wildcard (e.g. user%id matches user_id and userId). Use key: value syntax to match a specific key-value pair.
Limit search pathRestricts the search to a subtree. Paste a path copied from the Selected path panel (e.g. root>data>users>). The statistics (if enabled) are also scoped to this subtree.
Number searchFinds numeric values matching a condition. Set an optional key filter to restrict to values under a specific key name (e.g. version), choose an operator (=, ≠, >, <), and enter the target number.
Round (match rounded value)Before comparing, rounds the JSON value to the same number of decimal places as the input. For example, entering 1.23 matches 1.2345 but not 1.24.
Show statisticsWhen enabled, computes aggregate statistics over all matched numeric values and displays them below the toggles (see Statistics below).

Click Search (or press Enter in any search field) to run. Use Previous / Next to step through results. Each match is highlighted in the tree and its ancestors are expanded automatically.

Tip: A search only navigates within the active column — the other columns keep their expansion state.

Statistics

Tick Show statistics before (or after) running a number search. A panel expands showing the following values computed across all matched numbers:

StatDescription
nCount of matched numeric values.
SumTotal of all matched values.
MeanArithmetic average.
Std devPopulation standard deviation.
p50 (median)50th percentile — the middle value.
p9595th percentile.
p9999th percentile.

If Limit search path is set, statistics are scoped to the filtered results only. Toggling the checkbox updates the panel immediately without re-running the search.

Key value extractor

Enter a key name and click Extract (or press Enter) to collect every value stored under that key anywhere in the JSON. The output options are designed so the result can be pasted straight into a SQL IN (...) clause.

FieldWhat it does
KeyThe exact key name to search for. The extractor recurses the full tree and collects every value associated with a matching key, at any depth.
Limit search pathRestricts the extraction to a subtree. Paste a path from the Selected path panel (e.g. root>employees>) to narrow the scope.
QuoteWrap each value in ' single quotes, " double quotes, or nothing. Embedded quote characters are escaped SQL-style by doubling them (O'Brien → 'O''Brien').
Separator, + newline (one value per line with trailing commas), plain newline, or , inline (single line).
( )Wraps the whole list in parentheses.

Example — extracting id with quote ' and separator , + newline gives 'A-1', / 'A-2', / 'B-9', ready for a WHERE id IN (...). Changing the options re-formats the last extraction immediately, and Copy puts the output on the clipboard. null values are always emitted unquoted so they stay SQL NULL-friendly; objects and arrays are emitted as compact JSON.

Font size

The View section of the tools rail adjusts the tree font size between 8 px and 24 px with the − / + control. The current size is shown between the buttons.

Send to JSON Comparator

The → JSON Comparator button opens a modal. Choose a source for JSON A and JSON B — any memory slot, the current input, a file from disk, or a paste area — then click Open in Comparator →. The Comparator opens in a new tab with both sides already populated.

XML Viewer

View, navigate and search XML documents — same workspace as the JSON Viewer, with an extra table mode.

Open tool →

Layout and loading

Same single-screen workspace as the JSON Viewer: collapsible editor on the left (with line-number gutter and an error banner that extracts the parser's line/column and offers ↳ Jump to line N), the rendered content in the middle, and a tools rail on the right. Content renders automatically as you type; paste with Ctrl+V anywhere on the page, drop an .xml file anywhere, or use Open file. Format re-indents with the chosen indent size.

Tree and Table modes

The Tree / Table toggle in the toolbar switches the middle pane:

  • Tree — collapsible tree, fully collapsed by default. Alt+click a toggle to expand/collapse a whole subtree. Click any line to see its path (e.g. catalog/book[2]/@id — repeated sibling tags get a [n] index). Memory slot chips work exactly as in the JSON Viewer (click = show/hide column, Shift+click = save, double-click = load, right-click = rename; slots survive a reload) and let you view documents side by side.
  • Table — hierarchical detail view of the editor's document: children grouped by tag into tables, good for record-like XML. The Table navigation rail section opens or closes a group by tag path (e.g. body/book); paths copied from the tree work too — the [n] indexes are ignored.

Advanced search

Same search panel as the JSON Viewer, adapted to XML. It runs over the active column's document; text and number search can be combined.

FieldWhat it does
Text searchMatches tag names, attribute names/values, and text content (with Case sensitive and %-wildcard options). Use tag: value to match an element's text (e.g. author: Rossi), or @attr: value for attributes (e.g. @id: b2).
Limit search pathRestricts the search to a subtree. Paste a path from the Selected path panel (e.g. catalog/book[2]).
Number searchFinds numeric element text and attribute values matching a condition (=, ≠, >, <). The optional filter restricts to a tag name, or @name for attributes only. Round and Show statistics (n, sum, mean, std dev, percentiles) work exactly as in the JSON Viewer.

Previous / Next step through the matches — each one is expanded, highlighted, and its path shown in the Selected path panel.

Value extractor

Enter a tag name to collect the text content of every matching element, or @name to collect every matching attribute's value — optionally limited to a subtree path. The output options are the same as the JSON Viewer's extractor: quote (' / " / none, with SQL-style '' escaping), separator (, + newline / newline / inline), optional (...) wrap, and a Copy button — ready for a SQL IN (...) clause. A bare name matches both tags and attributes with that name; changing the options re-formats the last extraction immediately.

JSON Tracker

Import a browser HAR export and browse, filter and inspect every JSON response captured in the network traffic.

Open tool →

What is a HAR file?

A HAR (HTTP Archive) file is a JSON file that your browser's DevTools can export. It contains every network request and response — URL, method, status, headers, body, timing — exactly what you see in the Network panel.

Exporting from your browser

  1. Open DevTools (F12) and go to the Network tab.
  2. Interact with the page you want to inspect (load a page, click buttons, submit forms).
  3. Right-click any request in the list → Save All As HAR
    Firefox: Salva tutto come HAR  ·  Chrome: Save all as HAR with content
Tip: Enable "Persist logs" in DevTools before navigating so requests from previous pages are also captured.

Browsing entries

Drop the .har file onto the page or click the drop zone to browse. The tool defaults to showing only JSON responses; remove the filter to see all traffic.

The table shows method (color-coded), status code, URL (path only; full URL on hover), content type, response size, and response time. Click any row to preview the response in the right panel — JSON bodies are rendered as a collapsible tree; other bodies are shown as raw text. POST/PUT request bodies are shown too when present.

Filtering

FilterOptions
URL searchLive filter — matches any part of the full URL.
MethodGET, POST, PUT, PATCH, DELETE, OPTIONS, or All.
Status2xx, 3xx, 4xx, 5xx, or All.
TypeJSON only, or All.

The header checkbox selects or deselects all currently visible rows.

Sending to other tools

Tick one or more rows with the checkboxes, then use the action bar that appears:

  • Open in JSON Viewer — up to 4 entries are sent: the first loads into the editor, the rest into M1 / M2 / M3. The viewer opens in a new tab with the data pre-loaded and the tree already rendered.
  • Send to Comparator — available only when exactly 2 entries are selected. Both response bodies are sent to the JSON Comparator in a new tab.

String preparation

String Formatter

Turn a list of lines into quoted, comma-separated values — useful for SQL IN clauses or R vectors.

Open tool →

Usage

Paste one value per line into the input area. Choose single or double quotes and an output layout (vertical — one value per line — or inline). Optionally wrap the whole result in parentheses. Click Format to generate the output.

Also includes a Line Padder utility: pad each line to a fixed width with a configurable fill character, useful for aligning columns in text output.

SQL Insert Generator

Generate SQL INSERT statements from a CSV file.

Open tool →

Usage

  1. Paste CSV text or load a .csv file. The delimiter is detected automatically (comma, semicolon, or tab) but can be changed manually.
  2. The first row is treated as column headers. A column grid is shown — tick the Quote checkbox for each column whose values should be wrapped in single quotes in the output.
  3. Enter the target table name and click Generate. The result is a multi-row INSERT INTO … VALUES … statement.

SQL Update Generator

Generate SQL UPDATE statements from a CSV file.

Open tool →

Usage

  1. Paste or load a CSV. The delimiter is auto-detected.
  2. In the column grid, assign each column a role:
    • WHERE — used in the WHERE condition (key columns).
    • UPDATE — used in the SET clause.
    • Ignore — excluded from the output.
  3. Toggle Quote per column to wrap values in single quotes.
  4. Enter the table name and click Generate.

Race Calendar JSON Generator

Build a structured race-event JSON from a CSV — intended for use with the RaceCalendar app.

Open tool →

Usage

Paste or load a CSV where each row is a race or a session. A MAIN column (value 1 or 0) marks whether the row is a main race event or a sub-session. Configure the delimiter, then click Generate to produce the JSON. The tool groups sessions under their parent race and warns about any unmatched rows. Supports Excel date serial number conversion.

File comparison

JSON Comparator

Diff two JSON documents — structurally or as raw text.

Open tool →

Modes

ModeBehavior
fullStructural diff; object keys and array elements are both sorted before comparison. Two arrays with the same items in different order are considered equal.
orderedStructural diff; object keys are sorted, but array order is preserved. Use this when sequence matters.
exactRaw text diff, line by line. No parsing — whitespace and key order matter.

Differences are shown with + for lines only in the second document and − for lines only in the first. Click Format to pretty-print both inputs before comparing.

Tip: The → JSON Comparator button in the JSON Viewer and the Send to Comparator button in the JSON Tracker both populate this page automatically via a browser session handoff — no copy-pasting required.

XML Comparator

Diff two XML documents.

Open tool →

Usage

Paste XML or load files into the two panels. Choose between order-sensitive (child element order is significant) and order-insensitive modes, then click Compare. The result lists structural differences — missing elements, differing attribute values, mismatched text content.

CSV Comparator

Find rows that are present in one CSV but not the other.

Open tool →

Usage

Paste or load two CSV files. Configure the delimiter (comma, semicolon, tab) and whether to skip the header row and blank lines. Click Compare. The result is a two-column table: rows only in File A, and rows only in File B. A preview limit caps the display for large files.

The comparison is multiset-based: if a row appears twice in A and once in B, one copy is considered matched and one is reported as extra.

Digital image processing

Photo Slicer

Cut an image into equal rectangular tiles and download them.

Open tool →

Usage

  1. Load a JPG, PNG, or TIFF image.
  2. Set the number of horizontal and vertical cuts.
  3. Optionally enable Force square to crop the source image to a square before slicing.
  4. Choose the alignment (9-point grid: top-left, center, bottom-right, etc.) which determines which part of the image is kept when forcing a square crop.
  5. Set the output format (JPG / PNG) and JPEG quality.
  6. Click Slice. A live preview is shown; click Download all to get all tiles as individual files.

Booklet Maker

Turn a markdown file or an existing PDF into a print-ready, foldable A5 booklet.

Open tool →

The tool has two input modes, selected with the toggle at the top. Both produce the same kind of output: an A4 file with pages arranged (imposed) so that, printed double-sided and folded in half, they read in order as an A5 booklet you can staple along the fold.

From Markdown

  1. Load a .md/.txt file, or paste markdown text directly into the box.
  2. Set a title for the cover page, a body text size, and whether each # heading should start a new page, get a cover page and a table of contents.
  3. Optionally set a signature size (a multiple of 4) to split a long booklet into several stapled sections instead of one large one.
  4. Click Generate booklet. A live preview of the flat A5 pages appears; the summary shows the page and sheet counts.
  5. Download the A4 booklet (imposed, ready to print) and/or the A5 PDF (flat, for reading on screen).

Layout rules: # / ## / ### become section titles (an # starts a new page and appears in the table of contents); - / * / 1. become bullets; three or more -/*/_ force a page break; a blank line starts a new paragraph/stanza, and every other line is kept exactly as written (only wrapped if too wide) so manual line breaks in lyrics, poems and lists are preserved. Bold/italic/code markup is stripped, not styled. Text uses the standard PDF fonts (no embedding): accented Latin characters and common "smart" punctuation work; emoji/CJK/Cyrillic print as "?".

From an existing PDF

  1. Choose a PDF file. Any page size works: A4 pages are scaled down to A5, A5 pages fit as-is, and other sizes are centered and scaled to fill an A5 half (aspect ratio preserved).
  2. Optionally set a signature size, same as above.
  3. Click Impose PDF into booklet and download the imposed A4 file.

This mode keeps your pages exactly as they are — text and images alike — so it's the way to make a booklet with pictures or full styling: export your document to PDF first, then impose it here. The PDF is read entirely in your browser (nothing is uploaded). Pages that carry a /Rotate flag may not re-orient correctly; flatten/"print to PDF" them first if so.

Printing

Print the A4 file double-sided, flip on the short edge, at actual size (100%, no "fit to page"). Then fold every sheet in half and staple along the fold (saddle-stitch).
